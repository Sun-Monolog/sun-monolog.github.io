| 动词  | 假名  | 含义           |
| --- | --- | ------------ |
| 見る  | みる  | 看            |
| 居る  | いる  | 在、存在（人・动物）   |
| 起きる | おきる | 起床；（事情）发生    |
| 降りる | おりる | 下来、下车        |
| 借りる | かりる | 借            |
| 足りる | たりる | 足够、够用        |
| 生きる | いきる | 生存           |
| 落ちる | おちる | 掉落、下降、（考试）落榜 |
| 伸びる | のびる | 伸长、增长        |
| 似る  | にる  | 像…、相似        |
| 浴びる | あびる | 淋（浴、阳光 等）    |
| できる | できる | 会、能；完成、形成    |
| 着る  | きる  | 穿（衣服）  |
| 過ぎる | すぎる | 经过；过于… |
| 感じる | かんじる | 感到、感觉 |
| 信じる | しんじる | 相信 |

> 注意：
> **切る（きる「切断」）是五段，不是上一段**，活用是 きらない・きります 这种。
