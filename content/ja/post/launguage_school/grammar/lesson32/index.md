# きょうの表現・文型（今日重点表达/句型总结）

> 主题：原因说明 / 逆接意外 / 刚刚… / 容易・难 / 变化 / 目的 / 意志动词与无意志动词  

---

## 1) ～ので、～（因为…所以…）

### ✅ 意味
表示**后句结果的原因、理由**。语气比「～から」更**委婉、正式**。

### ✅ 接续
- 动词（普通形）＋ので  
- い形容词（普通形）＋ので  
- な形容词＋**なので**  
- 名词＋**なので**

### ✅ 例句
- 事故があったので、遅刻しました。（因为发生事故，所以迟到了。）

### 🔎 小提醒
很多情况下「ので」可以和「から」互换，但「ので」更柔和、更礼貌。

---

## 2) ～のに、～（明明…却… / 虽然…但是…）

### ✅ 意味
表示**根据前句事实本来会有某种预期**，但**结果与预期相反**。常带有说话人的**意外、不满、遗憾**等情绪。

### ✅ 接续
- 动词（普通形）＋のに  
- い形容词（普通形）＋のに  
- な形容词＋**なのに**  
- 名词＋**なのに**

### ✅ 例句
- 薬を飲んだのに、熱が下がりません。（明明吃了药，烧却没退。）

### ✅ 例句（课本）
- 一生懸命勉強したのに、不合格だった。  
- この部屋は、家賃が高いのに、古くて狭いです。  
- あの子は、まだ10歳なのに、もう大学で勉強しています。  
- （会话）あしたまでなのに…（明明到明天为止…）

---

## 3) ～たばかりです（刚刚… / 刚…不久）

### ✅ 意味
表示动作刚发生不久，强调**说话人主观感觉“刚刚”**。  
即使实际上过了一段时间，只要说话人觉得“还很近”，也可以用。

### ✅ 接续
- 动词た形（过去形）＋ばかりです

### ✅ 例句
- ４か月前に日本に来たばかりです。（我来日本才4个月。）

### 🔎 「～たばかり」vs「～たところ」
- **～たばかり**：主观“刚刚”，可有时间跨度  
- **～たところ**：客观“刚刚结束”，时间非常短  

例：
- ○ 去年、入社したばかりです。  
- × 去年、入社したところです。（时间太久，不自然）

### ✅ 例句（会话/练习）
- わたしも10分前に着いたばかりです。  
- 先週、来たばかりです。  
- このパソコン、先月買ったばかりなのに、動かないんです。  
- 荷物は、今朝届いたばかりです。

---

## 4) ～やすいです／～にくいです（容易… / 难以…）

### ✅ 接续
- 动词ます形去ます（动词词干）＋**やすいです／にくいです**

### ✅ 意味（两种情况）

#### ① 前接**意志动词**（做某行为容易/困难）
- **～やすい**：做某事很容易  
- **～にくい**：做某事很难

例：
- このスマホは、画面が大きいので、見やすいです。  
- この掃除機は、重いので、使いにくいです。  
- 「あたたかかった」は、言いにくいです。

#### ② 前接**无意志动词**（倾向强/弱）
- **～やすい**：某种现象更容易发生（倾向强）  
- **～にくい**：不容易发生（倾向弱）

例：
- 雨の日は、事故が起きやすいです。  
- この皿は、割れにくいです。  
- 安い傘は、壊れやすいです。  
- 夏の風邪は、治りにくいです。

### ✅ 例句（总例）
- 東京は便利なので、住みやすいです。（东京很方便，所以很宜居。）

### 口頭練習 1（意志动词：做起来容易/难）
**例1**  
このパソコンは、スクリーンが大きいです。見ます  
→ このパソコンは、スクリーンが大きいので、**見やすいです**。  

**例2**  
このパソコンは、スクリーンが小さいです。見ます  
→ このパソコンは、スクリーンが小さいので、**見にくいです**。  

**练习（把两句合成一句，用 ～やすい／～にくい）**
1. 新しいフライパンは、軽いです。料理します  
2. この辞書は、字が大きいです。読みます  
3. この炊飯器は、操作が簡単です。使います  
4. このかばんは、重いです。使います  
5. この店のおにぎりは、大きいです。食べます  
6. わたしのベッドは、硬いです。寝ます  

### 口頭練習 2（无意志动词：倾向强/弱）
**例1**  
夏は、洗濯物が乾きます  
→ 夏は、洗濯物が**乾きやすいです**。  

**例2**  
冬は、洗濯物が乾きます  
→ 冬は、洗濯物が**乾きにくいです**。  

**练习**
1. 紙の袋は、破れます  
2. ガラスのコップは、割れます  
3. 冬は、火事が起きます  
4. 値段が高い傘は、壊れます  
5. 癌は、治ります  
6. 車のガラスは、割れます

## 5) ～く／に なります（变得… / 成为…）

### ✅ 意味
表示状态变化：“变得～ / 变成～”。

### ✅ 接续（基本规则）
- い形容词：去い ＋ **く なります**  
  - 例：寒い → 寒くなります
- な形容词：＋ **に なります**  
  - 例：元気 → 元気になります
- 名词：＋ **に なります**  
  - 例：先生 → 先生になります

### ✅ 特例
- **いい → よくなります**

### ⚠️ 注意（课本提醒）
本身就包含“变化”意义的动词（如：痩せます、太ります、変わります 等）一般**不用**「～く／に なります」来表达。

### ✅ 例句
- 来週の金曜日、20歳になります。（下周五我就20岁了。）

### ✅ 例文（补充）
1. もうすぐ7月です。これから、だんだん**暑くなります**。  
2. ゆっくり休んだので、ずいぶん**元気になりました**。  
3. 洗剤で洗ったのに、きれいに**なりませんでした**。  
4. 来月、**高校生になります**。  
5. 薬を飲んだのに、風邪がなかなか**よくなりません**。  

### 口頭練習 1（い形容词 → くなりました）
**例** 最近、寒いです → 最近、**寒くなりました**。  
1. 眠いです  
2. 背が高いです  
3. 顔が赤いです  
4. 体調がいいです  

### 口頭練習 2（な形容词/名词 → になりました）
**例** 体が丈夫です → 体が**丈夫になりました**。  
1. 急に暇です  
2. 日本語が上手です  
3. 数学が好きです  
4. 部屋がきれいです

## 6) ～ように、～（为了… / 希望…就…）

### ✅ 结构（课本版）
- **動1（辞書形／ない形）＋ように、動2**
  - **動1**：目的/目标状态  
  - **動2**：为达成目标而做的**意志性动作**

### ✅ 意味
表示**目的/目标**：为了达到前项状态而做后项行动。

### ⚠️ 動1 的常用限制
動1 常用：
- **无意志动词的辞书形**（如：治る、聞こえる、できる、間に合う 等）
- 或 **动词否定形**（如：忘れない、遅れない、間違えない）

### ✅ 例句
- 風邪が治るように、薬を飲みます。（为了让感冒好起来，我吃药。）

### ✅ 例文（补充）
1. 日本語が上手に話せるように、毎日、シャドーイングをしています。  
2. 試験に間に合うように、タクシーで行きます。  
3. 約束を忘れないように、メモをします。  

### 口頭練習 1（肯定：～できる／～間に合う／～治る）
**例** JLPTに合格できます・毎日、勉強しています  
→ JLPTに合格できるように、毎日、勉強しています。  

1. 泳げます・毎日、プールに通っています  
2. いい車が買えます・貯金しています  
3. 試合に勝てます・一生懸命練習しています  
4. 授業に間に合います・急ぎましょう  
5. 風邪が治ります・早く寝ます  

### 口頭練習 2（否定：～ないように）
**例** 忘れません・メモをします  
→ 忘れないように、メモをします。  

1. 家族が心配しません・毎日、電話をかけています  
2. 虫歯になりません・食後に歯を磨いてください  
3. 道を間違えません・地図で確認します  
4. 授業に遅れません・家を早く出ます  
5. 大事な書類をなくしません・しまっておきます

## 7) 意志動詞（いしどうし）と無意志動詞（むいしどうし）

### ✅ 定义
- **意志動詞**：表示**人的意志性动作**的动词  
  - 例：読む、食べる、走る など
- **無意志動詞**：表示**事物的运动/变化**，或**人的生理・心理现象**等（非意志控制）的动词  
  - 例：壊れる、割れる  
  - 例：お腹が空く、喉が渇く、飽きる  
  - 例：出会う、間違う など  
  - 也常包括：人的消极动作、**受身动词**、**可能动词** 等

### ⚠️ 注意
一个动词也可能同时属于两类（例如：**なる、忘れる、落とす** 等）。

### ✅ 对比例
- 携帯をうちに**忘れて**来てしまった。（无意志：不小心忘了）  
- 彼女のことは、早く**忘れたい**。（意志：想要忘掉）

## 综合小练习（可选）
把两个短句连成一句（自由发挥）：
1. 電車が遅れました。遅刻しました。→（～ので）
2. たくさん寝ました。まだ眠いです。→（～のに）
3. 先週、この学校に入りました。→（～たばかり）
4. この漢字は難しいです。覚える（おぼえる）。→（～にくい）
5. 暖かいです。→（～くなります）
6. 忘れない（わすれない）。メモします。→（～ように）
