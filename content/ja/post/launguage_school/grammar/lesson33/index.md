# 本课语法要点总结

> 主题：**表示“时间（～とき）”**、**变化/变得会（～ようになります / ～なくなります）**、**努力养成习惯（～ようにしています）**、**目的/为了（～ために）**，以及“过去和现在的对比表达”。

---

## 1. ～とき（……的时候）

### ✅ 接续
- **动词普通形 + とき**
- **い形容词普通形 + とき**
- **な形容词 + な + とき**
- **名词 + の + とき**

> 注意：**な形**要用「なとき」，**名词**要用「のとき」。

### ✅ 含义
- 表示后句动作/状态成立的时间：**“在……的时候”**
- 当前后句都是动作性动词时，有时也表示**动作的先后关系**（谁先发生）

### ✅ 例句
- 父は、新聞を読むとき、いつも眼鏡をかけます。  
  爸爸看报纸的时候，总是戴眼镜。
- 学校に来るとき、コンビニで劉さんに会いました。  
  来学校的时候，在便利店遇到了小刘。
- 学校に着いたとき、忘れ物に気がつきました。  
  到学校的时候，发现忘东西了。
- 勉強で大変なとき、好きな歌を聞いて頑張ります。  
  学习很辛苦的时候，听喜欢的歌来加油。
- 子どものとき、野菜が嫌いでした。  
  小时候不喜欢蔬菜。

### ✅ 口头练习
- 道を渡るとき、車に気を付けてください。  
  过马路的时候，请注意车辆。
- 咳が出ます。いつもこの薬を飲みます。  
  → 咳が出るとき、いつもこの薬を飲みます。
- 時間があります。ぜひ遊びに来てください。  
  → 時間があるとき、ぜひ遊びに来てください。
- 漢字の読み方がわかりません。辞書で調べます。  
  → 漢字の読み方がわからないとき、辞書で調べます。
- 眠れません。本を読みます。  
  → 眠れないとき、本を読みます。

## 2. ～ようになります（变得……/开始能够……）

### ✅ 接续
- **动词辞书形 + ようになります**
- 常见接**可能形/能力表达**：読める、聞き取れる、乗れる 等

### ✅ 含义
表示能力、状况、习惯等的变化：  
- “变得会……了 / 开始能……了 / 变得……起来了”

### ✅ 例句
- 最近、日本語で小説が読めるようになりました。  
  最近变得能用日语读小说了。
- 前は、泳げませんでしたが、今は、泳げるようになりました。  
  以前不会游泳，但现在会了。
- 親の気持ちがわかるようになりました。  
  变得能理解父母的心情了。
- （会话）  
  A：いつ自転車に乗れるようになりましたか。  
  B：小学生のとき、乗れるようになりました。  
- 日本語のニュースが聞き取れますか。  
  いいえ、まだよく聞き取れません。聞き取れるようになりたいです。  
- 日本に来てから、料理をするようになりました。  
- インターネットでコンサートのチケットが買えるようになりました。

---

## 3. ～なくなります（不再…… / 变得不……了）

### ✅ 位置与用法
- 常用来表示**“～ようになります”的否定变化**  
- 比起「～ないようになりました」，更多时候用 **～なくなりました**

### ✅ 接续
- **动词ない形 → ない を去掉 + なくなります**
  - 行かない → 行か**なくなります**
  - 見ない → 見**なくなります**

### ✅ 例句
- （例）最近、田中さんが遅刻しないようになりました。  
  / 最近、田中さんが遅刻しなくなりました。  
  最近田中不再迟到了。（后者更常用）
- （对比练习）  
  泳げました → 泳げません  
  ⇒ 泳げなくなりました。

### ✅ 练习
- 甘い物を食べません → 甘い物を食べなくなりました。  
- たばこを吸いません → たばこを吸わなくなりました。  
- SNSを見ません → SNSを見なくなりました。  
- 運動しません → 運動しなくなりました。  
- 小さい字が読めません → 小さい字が読めなくなりました。  
- ズボンが履けません → ズボンが履けなくなりました。  
- 自転車に乗れません → 自転車に乗れなくなりました。

---

## 4. ～ようにしています（努力做到…… / 尽量养成……习惯）

### ✅ 接续
- **动词辞书形 + ようにしています**
- **动词ない形 + ようにしています**

### ✅ 含义
表示说话人有意识地努力/注意去做（或不做）：  
- “尽量…… / 努力养成…… / 注意不要……”

### ✅ 例句
- 毎日、単語を５つ覚えるようにしています。  
  我努力做到每天记5个单词。
- 朝ごはんをきちんと食べるようにしています。  
  我尽量好好吃早饭。
- 冷たい物を飲まないようにしています。  
  我尽量不喝冷的。
- （会话）  
  A：毎日、運動しているんですか。  
  B：毎日ではありませんが、できるだけ運動するようにしています。  

### ✅ 口头练习
- 毎日、２時間勉強します  
  → 毎日、２時間勉強するようにしています。
- 朝、早く起きます  
  → 朝、早く起きるようにしています。
- 自分でご飯を作ります  
  → 自分でご飯を作るようにしています。
- 毎月、１冊本を読みます  
  → 毎月、１冊本を読むようにしています。
- 日本語で日記を書きます  
  → 日本語で日記を書くようにしています。
- できるだけ日本語で話します  
  → できるだけ日本語で話すようにしています。
- 授業の１０分前に学校に来ます  
  → 授業の１０分前に学校に来るようにしています。

---

## 5. ～ために（为了…… / 以……为目的）

### ✅ 接续
- **动词辞书形 + ために**
- **名词 + の + ために**

### ✅ 含义
1) 表示目的：**“为了……（去做后句）”**（带意志、目的性强）  
2) 接人/组织等名词时，可表示**“为了某人/某组织的利益、恩惠”**

### ✅ 例句
- 大学に入るために、日本に来ました。  
  为了上大学，来到了日本。
- 日本の大学に入るために、日本語を勉強しています。  
  为了考上日本的大学，在学习日语。
- 安全のために、シートベルトをします。  
  为了安全系安全带。
- 父は、家族のために、毎日、働いています。  
  爸爸为了家人每天工作。

### ✅ 口头练习
- 受験のために、EJUとJLPTに申し込みます。  
  为了考试报名EJU和JLPT。
- 健康のために、野菜や果物を食べます。  
  为了健康吃蔬菜水果。
- 引っ越しのために、荷物をまとめます。  
  为了搬家整理行李。
- 面接のために、スーツを買います。  
  为了面试买西装。
- 出願のために、母国の卒業証明書と成績証明書を準備します。  
  为了申请准备毕业证明和成绩证明。

## 6. 过去 vs 现在：昔は～ましたが、今は～ません（对比变化）

### ✅ 形式
- **昔は～ましたが、今は～ません。**
- 也常与 **～なくなりました** 连用表达“现在不再……”

### ✅ 例句
- 昔は、よく公衆電話を見ましたが、今は、見なくなりました。  
  以前经常能看到公用电话，但现在不再看到了。

### ✅ 表格练习
- 星が見えました → 今：見えません  
- 新幹線でたばこが吸えました → 今：吸えません  
- この川に魚がいました → 今：いません  
- よく手紙を書きました → 今：書きません  

---

## 速记对照（本课核心区别）

- **～とき**：时间点/时间段（……的时候）
- **～ようになります**：能力/状态发生变化（变得会……）
- **～なくなります**：不再……（变化的否定结果）
- **～ようにしています**：主观努力、刻意养成（尽量……）
- **～ために**：目的/为了（目的性强，常用于计划、努力、行动）
- **昔は～今は～**：过去与现在的对比（强调变化）
