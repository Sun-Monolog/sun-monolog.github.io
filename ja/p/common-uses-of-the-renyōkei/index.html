連用形の使い方

動詞の連用形の使い方

11月 12, 2025
読了時間: 2分

与助动词「たい」连用（愿望）

结构： 连用形 + たい

功能： 表示“想做某事”

例句：

  • 日本へ行きたい。→ 想去日本。
  • 寿司を食べたい。→ 想吃寿司。

注： たい 是形容词（い形容词），所以它的否定、过去都按形容词活用：

  • 行きたくない（不想去）
  • 行きたかった（曾经想去）

与助动词「すぎる」连用（过度）

结构： 连用形 + すぎる

功能： 表示“过于……”、“太……”

例句：

  • 食べすぎる → 吃太多
  • 寝すぎた → 睡太久了
  • 飲みすぎないで → 别喝太多

与「に」「方」「やすい／にくい」等构成复合名词或形容词

结构： 连用形 + 名词／形容词化要素

功能： 名词化、形容词化

结构含义例句
連用形 + 方～的方法書き方（写法）・使い方（用法）
連用形 + にくい难以～食べにくい（难吃）
連用形 + やすい容易～飲みやすい（好喝）
連用形 + に目的状语勉強しに行く（去学习）

与「ながら」「つつ」连用（同时进行）

结构： 连用形 + ながら／つつ

功能： 表示“～的同时”、“一边～一边～”

例句：

  • 音楽を聞きながら勉強する。→ 一边听音乐一边学习。
  • 反省しつつ努力する。→ 一边反省一边努力。

「そうだ」「始める」「終わる」等构成复合动词

结构： 连用形 + 动词／助动词

功能： 表示状态、起始、结束、持续等

结构含义例句
連用形 + 始める开始～勉強し始める（开始学习）
連用形 + 終わる结束～読み終わる（读完）
連用形 + 続ける继续～働き続ける（持续工作）
連用形 + そうだ看起来要～雨が降りそうだ（看起来要下雨）

名词化・副词化用法

有时候连用形直接变成名词或副词使用。

例句：

  • 笑い（连用形）→ 笑い声（笑声）
  • 飛び（连用形）→ 飛び出す（飞出）
  • 速く（形容词连用形）→ 副词用法「跑得快」：速く走る。
